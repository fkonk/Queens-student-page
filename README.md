# queens-student-page

Personal student page for CISC 121 at Queen's University, hosted with GitHub Pages.

## Files
- `index.html` — page content (About, Courses, Projects, Contact)
- `style.css` — Queen's colours and layout
- `me.jpg` — profile photo (compressed to ~120 KB)

## Updating
Edit `index.html` for content or `style.css` for styling, then commit to `main`. GitHub Pages redeploys automatically.
